What is in the repo

1

pipeline

A job graph with topological order, parallel layers, a critical path and "what is affected" queries. An artifact cache, a priority scheduler and an async executor sit on top.

2

observability

Sliding-window metrics, a streaming log aggregator and rule-based alerts, built on a metric backend protocol.

3

infra

Layered config with deep merge, a generator-based drift detector and a snapshot state store that hands out copies, so callers cannot corrupt state.

No third-party dependencies. The README is organized around the Python features each module shows: generators, iterator protocols, dataclasses with slots, protocols, pattern matching, context managers and asyncio.

Install

Python 3.12 or later. Standard library only.

git clone https://github.com/gerardrecinto/platform-toolkit
cd platform-toolkit
pip install -e .
from pipeline import DAG
dag = DAG.from_dict({
    "build": {"command": "make", "depends_on": []},
    "test":  {"command": "pytest", "depends_on": ["build"]},
})
for layer in dag.layers():
    print([n.name for n in layer])
What this does not do
  • It is a library of building blocks, not a CI system. It does not run your jobs on a runner.
  • The page graphs and diffs. It does not execute the commands in the job graph.
  • The README says the code is refined from years of CI/CD work. Nothing on this page measures that.
